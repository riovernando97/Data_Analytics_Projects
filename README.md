# 📊 Data Analytics Projects Repository

Repository ini berisi kumpulan project Data Analyst yang dibuat menggunakan berbagai tools seperti:
- Excel
- MySQL
- Python
- Power BI

Tujuan repository ini adalah sebagai portofolio profesional untuk menunjukkan kemampuan analisis data, pembuatan dashboard, data cleaning, dan storytelling dengan data.

---

## 📁 Struktur Repository
- excel-projects/
- mysql-projects/
- python-projects/
- powerbi-projects/


---

## 🧰 Tools yang Digunakan
- Excel
- MySQL Workbench
- Python (Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn)
- Power BI Desktop

## 🎯 Tujuan Portofolio
- Mengembangkan skill analisis data
- Membangun portofolio untuk kebutuhan kerja sebagai Data Analyst
- Menerapkan teknik data cleaning, EDA, dan visualisasi
